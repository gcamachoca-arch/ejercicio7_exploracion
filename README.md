Descripción del Proyecto

Este proyecto forma parte del simulador de exploración espacial desarrollado para la Universidad CENFOTEC. En este Segundo Avance, el sistema gestiona la fase de ejecución de la misión espacial mediante dos programas independientes programados en Python:

ejercicio7_exploracion.py: Controla la etapa de exploración científica en destino a través de un menú interactivo en ciclo. Realiza seguimiento del consumo de energía y provisiones, contabiliza actividades realizadas y muestras recolectadas, y acumula los puntos científicos obtenidos.

ejercicio8_regreso.py: Evalúa si la nave cuenta con suficiente combustible para realizar el viaje de regreso a la Tierra (Caso A: simulación día a día del viaje con control de consumo y detección de fallos) o si la tripulación queda varada (Caso B: cálculo de días de supervivencia por recurso y determinación del recurso limitante utilizando condicionales simples y sin hacer uso de min()).
